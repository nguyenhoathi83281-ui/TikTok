## 📦 准备工作

### 你需要准备的东西

1. **电脑系统**
   - Windows 10/11
   - macOS 10.15+
   - Linux (Ubuntu 18.04+)

2. **必需软件**
   - Node.js 16.0.0 或更高版本
   - 文本编辑器（记事本、VSCode、Sublime等都可以）
   - 浏览器（Chrome、Firefox、Safari、Edge都可以）

3. **网络要求**
   - 能访问互联网
   - 如果使用OpenAI，国内用户可能需要代理

4. **资金准备**（可选）
   - OpenAI: 约$10起充值
   - DeepSeek: 约¥50起充值
   - Google Gemini: 有免费额度

### 检查Node.js是否已安装

打开终端（命令行），输入：

```bash
node -v
```

**如果显示版本号**（如：v18.17.0），说明已安装 ✅
**如果显示"找不到命令"**，需要先安装Node.js 👇

#### 如何安装Node.js

**Windows/Mac用户：**
1. 访问 https://nodejs.org/
2. 下载LTS版本（推荐）
3. 双击安装包，一路下一步
4. 安装完成后，重新打开终端，再次输入 `node -v` 验证

**Linux用户：**
```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证安装
node -v
npm -v
```

## 🛠️ 安装配置

### 第一步：打开项目文件夹

**方式A：使用文件管理器**
1. 找到下载的项目文件夹 `tiktok-viral-agent`
2. 进入 `backend` 文件夹
3. 在空白处右键 → "在终端中打开"（或"在此处打开命令行窗口"）

**方式B：使用命令行**
```bash
cd /path/to/tiktok-viral-agent/backend
# 例如：
cd ~/Downloads/tiktok-viral-agent/backend  # Mac/Linux
cd C:\Users\YourName\Downloads\tiktok-viral-agent\backend  # Windows
```

### 第二步：创建配置文件

在终端中输入：

```bash
cp .env.example .env
```

**如果提示"cp不是内部命令"（Windows）：**
```bash
copy .env.example .env
```

这个命令会创建一个名为 `.env` 的文件。

### 第三步：编辑配置文件

**方法1：使用记事本（最简单）**

Windows:
```bash
notepad .env
```

Mac:
```bash
open -e .env
```

Linux:
```bash
nano .env
```

**方法2：使用文件管理器**
1. 在文件管理器中显示隐藏文件
   - Windows: 查看 → 勾选"隐藏的项目"
   - Mac: Command + Shift + .
2. 找到 `.env` 文件
3. 右键 → 用记事本打开

### 第四步：填写API Key

在打开的 `.env` 文件中，找到对应的位置，填入你的API Key。

**如果你用的是DeepSeek：**
```env
# 找到这两行，删除前面的 # 号，填入你的Key
DEEPSEEK_API_KEY=你刚才复制的DeepSeek密钥
DEEPSEEK_MODEL=deepseek-chat
```

**完整示例：**
```env
# 服务器配置
PORT=3000
NODE_ENV=development

# DeepSeek配置（如果用DeepSeek，就填这个）
DEEPSEEK_API_KEY=sk-1234567890abcdef1234567890abcdef
DEEPSEEK_MODEL=deepseek-chat

# OpenAI配置（如果用OpenAI，就填这个）
# OPENAI_API_KEY=sk-proj-你的OpenAI密钥
# OPENAI_MODEL=gpt-4-turbo-preview

# 其他的不用管，保持原样即可
```

**重要提醒：**
- ✅ 只需要填一个API Key就可以了！
- ✅ 填完后保存文件（Ctrl+S 或 Command+S）
- ⚠️ 注意不要有多余的空格
- ⚠️ Key要完整复制，不要漏掉任何字符

### 第五步：安装依赖

在终端中输入：

```bash
npm install
```

**你会看到：**
```
npm WARN deprecated ...  （这些警告可以忽略）
added 234 packages in 45s
```

等待几分钟，直到安装完成。

## ❓ 常见问题

### Q1: 启动失败，显示"端口3000已被占用"

**原因：** 3000端口被其他程序占用

**解决方案：**

**方法1：关闭占用端口的程序**
```bash
# Windows
netstat -ano | findstr :3000
taskkill /PID <进程ID> /F

# Mac/Linux
lsof -i :3000
kill -9 <进程ID>
```

**方法2：更改端口**
1. 打开 `.env` 文件
2. 修改第一行：`PORT=8080`（或其他端口）
3. 保存后重启服务
4. 访问 `http://localhost:8080`

---

### Q2: 生成失败，提示"API错误"

**可能原因1：API Key错误**
- 检查 `.env` 文件中的Key是否完整
- 确认没有多余的空格或换行
- 确认Key没有过期

**可能原因2：余额不足**
- 登录AI服务商后台检查余额
- 及时充值

**可能原因3：网络问题**（OpenAI）
- 国内访问OpenAI需要代理
- 建议切换到DeepSeek或Gemini

**解决步骤：**
1. 打开浏览器访问 `http://localhost:3000/api/health`
2. 查看返回的状态信息
3. 确认API Key是否被识别

---

### Q3: 页面打不开，显示"无法访问"

**原因：** 后端服务未启动

**解决：**
1. 检查终端是否有报错
2. 确认看到了启动成功的界面
3. 尝试重启服务：
   ```bash
   # 按 Ctrl+C 停止
   # 然后重新启动
   npm start
   ```
